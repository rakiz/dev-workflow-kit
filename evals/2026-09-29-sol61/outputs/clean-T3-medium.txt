- **Minor — Exclusion results leak between calls** (`incremental.py:10–15`). The mutable default `excluded=[]` is reused and appended to across invocations. After `filter_excluded([".git/config"])`, calling `filter_excluded(["notes.txt"])` still returns `[".git/config"]`, violating the promise to return a subset of the current input.

- **Major — Failed copies are reported as completed** (`incremental.py:23–24`). `copy_file()` suppresses `OSError` internally, so `copy_many()` appends the destination even when copying failed. With a nonexistent source, it returns the destination in `done` although no destination file exists. Callers relying on this result to update bookkeeping can mark uncopied files as synchronized and skip retries.

- **Major — Manifest merging discards valid updates with older timestamps** (`incremental.py:38–39`). A changed source file can have a lower mtime after restoring a backup or checking out an older revision. The merge retains the previous state solely because its mtime is higher, even if the new size differs. For example, old `{size: 5, mtime: 200}` overrides new `{size: 10, mtime: 100}`, leaving the manifest inconsistent with the newly synchronized file.
