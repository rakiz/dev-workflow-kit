- **Minor — `incremental.py:10–15`: Exclusion results leak across calls.** The default `excluded=[]` is shared and mutated. After `filter_excluded([".git/config"])`, calling `filter_excluded(["notes.txt"])` incorrectly returns `[".git/config"]`. Subsequent calls also mutate previously returned results.

- **Major — `incremental.py:23–24`: Failed copies are reported as completed.** `copy_file()` suppresses `OSError`, so `copy_many()` appends the destination even when the source is missing or the destination write fails. Reproduced with a nonexistent source: the destination appears in `done` despite never being created. Callers trusting this completion list can record uncopied or partially written files as synchronized.

- **Major — `incremental.py:38–39`: Valid updates with older timestamps are discarded.** A changed file can have a lower mtime after restoring a backup or copying timestamp-preserved files. Given an existing state `{size: 5, mtime: 200}` and a new state `{size: 9, mtime: 100}`, the merge retains the old state. This leaves the manifest inconsistent with successfully copied content and can cause later change detection to skip a necessary copy if the source returns to the retained state.
