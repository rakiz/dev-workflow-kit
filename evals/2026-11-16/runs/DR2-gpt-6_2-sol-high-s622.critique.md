**Revise the design before coding.** The first decisions are how to guarantee a single writer, what a crash can leave behind, and when it’s safe to delete. Then validate the polling budget.

1. **Hold one lock for the daemon’s lifetime** ([DESIGN.md:41–48](DESIGN.md#L41)). A per-poll lock lets a second daemon start, and releasing it before commit permits lost updates. Size and mtime don’t make concurrent manifest rewrites mergeable. Use an OS-backed exclusive lock per destination, acquired before recovery and held through shutdown.
2. **Publish copies and checkpoints atomically** ([DESIGN.md:25–37](DESIGN.md#L25)). Re-statting after writing cannot undo a partial file already visible in `dst`. Stream into a temp file beside the destination, validate the source, then atomically replace. An incremental journal can’t reconstruct unchanged entries from a torn manifest. Keep an atomic checkpoint and specify durability and replay ordering, or drop the journal if startup reconciliation against both trees meets the recovery goal.
3. **Make change detection and deletion conservative** ([DESIGN.md:38–51](DESIGN.md#L38), [57–58](DESIGN.md#L57), [72–73](DESIGN.md#L72)). Same-size edits within one second can be missed forever. Use nanosecond metadata in versioned daemon state and decide whether metadata-preserving edits require content verification. Treat unreadable or incompletely scanned subtrees as unknown; delete only on confirmed absence.
4. **Design for sustained overload, not just small bursts** ([DESIGN.md:12–24](DESIGN.md#L12), [63–68](DESIGN.md#L63)). The 500 ms loop budgets for a scan but also has to copy and commit. At that cadence, 50,000 files means roughly 100,000 metadata checks/sec before copying. A build burst can span many polls, and a continuously changing file can debounce indefinitely. Measure full-cycle p95 on representative trees during builds; bound copy work per cycle, coalesce by path, commit only when dirty, and track oldest pending age. Keep polling only if those measurements support the latency target.
