+"""Incremental sync helpers added in v0.2 (commit under review)."""
+import json
+import os
+
+from synccli import copy_file
+
+EXCLUDE_TOP_DIRS = {".git", "__pycache__", ".sync_manifest.json"}
+
+
+def filter_excluded(paths, excluded=[]):
+    """Return the subset of paths that must be excluded from sync."""
+    for p in paths:
+        if p.split(os.sep)[0] in EXCLUDE_TOP_DIRS:
+            excluded.append(p)
+    return excluded
+
+
+def copy_many(pairs):
+    """Copy a batch of (src, dst) pairs; return the list of dst paths done."""
+    done = []
+    for src, dst in pairs:
+        try:
+            copy_file(src, dst)
+            done.append(dst)
+        except Exception:
+            continue
+    return done
+
+
+def merge_manifest(dst_manifest_path, new_manifest):
+    """Merge new file states into the destination manifest."""
+    old = {}
+    if os.path.exists(dst_manifest_path):
+        with open(dst_manifest_path, "r", encoding="utf-8") as f:
+            old = json.load(f)
+    merged = dict(old)
+    for rel, state in new_manifest.items():
+        if rel not in old or old[rel]["mtime"] <= state["mtime"]:
+            merged[rel] = state
+    return merged

Defects in `incremental.py` (commit d339404):

1. **Major: `filter_excluded`, mutable default argument (`excluded=[]`).** The list is shared across all calls. Excluded paths accumulate from one call to the next. A second call therefore also returns the first call's exclusions, even for different paths. Files that should not be are then treated as excluded. Use `None` and create the list inside the function.

2. **Major: `copy_many` swallows all errors.** `except Exception: continue` logs nothing and raises nothing. The caller only sees the `done` list. It cannot distinguish a failure from a skipped entry. If the caller then updates the manifest from the expected files rather than from `done`, it records never-copied files as synced. Errors should be collected and returned or raised.

3. **Major: `merge_manifest` writes nothing and is not atomic.** The name and docstring talk about merging into the destination manifest. The function only returns a dict, without ever writing it. If the caller writes it with a direct `open(..., "w")`, a crash at that moment corrupts the manifest. A `json.load` on an empty or truncated manifest also raises an unhandled exception. The write should go through a temp file followed by an `os.replace`.

4. **Minor: `merge_manifest`, `["mtime"]` access without a guard.** An entry without an `mtime` key, in the old or the new manifest, raises a `KeyError`. With `<=`, an entry older than the manifest's does not replace it, which is intended. However, a file deleted or reverted to an earlier mtime (restore, `touch -d`) keeps a stale state.

5. **Minor: `filter_excluded`, comparison on the first path segment only.** On an absolute path, `split(os.sep)[0]` is `""`, so nothing is excluded. A nested `__pycache__` is not excluded either. The name `EXCLUDE_TOP_DIRS` indicates it is intentional, but the contract is undocumented and paths with `./` escape the filter.

I did not verify `synccli.copy_file` (signature, copy atomicity). Points 2 and 3 depend on how the caller uses these functions.
