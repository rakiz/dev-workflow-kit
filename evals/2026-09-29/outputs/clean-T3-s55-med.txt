"""synccli: synchronize a source directory into a destination using a manifest."""
import argparse
import json
import os
import sys

MANIFEST_NAME = ".sync_manifest.json"


def scan_files(root):
    """Return sorted list of relative file paths under root."""
    result = []
    for dirpath, dirnames, filenames in os.walk(root):
        dirnames[:] = [d for d in dirnames if not d.startswith(".")]
        for name in filenames:
            full = os.path.join(dirpath, name)
            rel = os.path.relpath(full, root)
            result.append(rel)
    return sorted(result)


def file_state(path):
    """Return (size, mtime) for a file."""
    st = os.stat(path)
    return {"size": st.st_size, "mtime": st.st_mtime}


def build_manifest(root):
    """Build a manifest {relpath: state} for all files under root."""
    manifest = {}
    for rel in scan_files(root):
        manifest[rel] = file_state(os.path.join(root, rel))
    return manifest


def changed_files(old_manifest, new_manifest):
    """Return files whose state changed or that are new in new_manifest."""
    changed = []
    for rel, state in new_manifest.items():
        if rel not in old_manifest or old_manifest[rel] != state:
            changed.append(rel)
    return changed


def collect_stale(items, seen=None):
    """Collect stale entries: items not yet marked fresh.

    Args:
        items: iterable of (path, fresh) tuples.
        seen: set of paths already marked fresh; defaults to a fresh set.
    """
    if seen is None:
        seen = set()
    stale = []
    for i in range(1, len(items)):
        path, fresh = items[i]
        if path not in seen and not fresh:
            stale.append(path)
    return stale


def copy_file(src, dst):
    """Copy src to dst, creating parent directories as needed."""
    os.makedirs(os.path.dirname(dst) or ".", exist_ok=True)
    try:
        with open(src, "rb") as fsrc, open(dst, "wb") as fdst:
            fdst.write(fsrc.read())
    except OSError:
        pass  # unreadable source: skip it, next pass will retry


def sync(src_root, dst_root, dry_run=False):
    """Sync src_root into dst_root; return list of copied relative paths."""
    src_manifest = build_manifest(src_root)
    dst_manifest_path = os.path.join(dst_root, MANIFEST_NAME)
    old_manifest = {}
    if os.path.exists(dst_manifest_path):
        with open(dst_manifest_path, "r", encoding="utf-8") as f:
            old_manifest = json.load(f)
    to_copy = changed_files(old_manifest, src_manifest)

Defects of the HEAD commit (d339404), in `incremental.py`:

1. **Major: `filter_excluded` has a mutable default argument (`excluded=[]`).** The list is shared across all calls without a second argument. Each call therefore also returns the previous calls' exclusions. A file excluded at one call appears in the results of later calls, including for paths that should not be. The "the subset of `paths` to exclude" contract is false. Use `excluded=None` then `excluded = []`.

2. **Major: `copy_many` can announce copies that never happened.** `copy_file` (in `synccli.py`) already swallows `OSError` with a `pass`. It therefore never raises for an unreadable source. `copy_many` then adds `dst` to `done` even though nothing was copied, or the destination file was truncated. Indeed, `open(dst, "wb")` runs before the source is read and empties the destination file. The "the list of dst done" contract is misleading. If the caller uses `done` to update the manifest, that manifest becomes corrupted: it declares synced a file that is missing or empty, which will never be retried.

3. **Major: `copy_many` swallows any exception (`except Exception: continue`).** Failures are silent, with no log and no returned error list. The caller cannot distinguish a failure from a file it did not request. There is a silent data-loss risk, especially combined with point 2.

4. **Major: `merge_manifest` crashes or corrupts state on an invalid manifest.** A truncated or corrupted `.sync_manifest.json` raises an unhandled `JSONDecodeError`. An old entry without the `mtime` key raises a `KeyError`. The manifest is not written atomically, but that point is mostly the caller's responsibility. This defect is major if this function is wired into `sync`, otherwise minor.

5. **Minor: `merge_manifest`'s merge rule (`old.mtime <= new.mtime`) compares only the `mtime`s.** If a file is modified while keeping an older `mtime`, e.g. after a restore from backup, the new state is ignored. The manifest then keeps the old size and the old `mtime`, and the modification is no longer detected. The merge also ignores files deleted from the source: stale entries remain forever.

6. **Minor: `filter_excluded` only tests the first path segment.** It works for `.git/…`, but not for a nested `.git` or `__pycache__` (`pkg/__pycache__/x.pyc`). `scan_files` already ignores dot-directories, so the filter is partly redundant. It lets `__pycache__` through in subfolders.

7. **Minor: `from synccli import copy_file` creates coupling.** The commit adds no tests, and these functions are not called from `sync`. They are therefore not wired in: the corrupted state of points 2 to 4 is not yet reachable, but it will be as soon as they are used.
