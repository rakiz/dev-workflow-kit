**Objective:** Add `--json` flag to argparse, plus the JSON output logic: collect data from `sync()`, compute skipped count, print the required JSON object to stdout (and nothing else when `--json` is set).

**Files to modify:**

| File | Change |
|---|---|
| `synccli.py` | Add `--json` flag to `parser.add_argument` in `main()`. **Skipped count strategy:** `skipped` = `len(src_manifest) - len(copied)`. Access the src manifest without changing `sync()`'s return — call `build_manifest(args.src)` in `main()` (it already exists and is cheap). Alternatively, compute skipped inside `sync()` and return a richer structure — but GOAL.md says keep signature stable. Best path: compute it in `main()` after `sync()` by building the manifest separately (minor cost, zero risk to `sync()`).

**Agent:** `cheap-code`

**Risks:**
- Low: accidentally printing newline/extra text in JSON mode (violates "nothing else may be printed").
- Low: `build_manifest` called twice if not careful (once in `sync()`, once in `main()`). Acceptable cost; avoids changing `sync()` signature.

**Acceptance criterion:** `python3 -m synccli src dst --json` prints exactly one JSON object on stdout with all required keys, exits 0, no other stdout. `--json --dry-run` prints same shape with `copied` listing what WOULD be copied.
